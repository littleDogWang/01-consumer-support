# 消费电子售后支持验收标准

## 必须通过

- 有效订单号能返回对应产品和保修状态。
- 无效订单号不会生成虚构订单信息。
- 工具返回的数据与 Agent 话术一致。
- 售后写入操作未实现时，Agent 不声称已完成退款、换货或工单创建。
- 查询失败后能给出人工处理路径。
- transcript、Agent 状态、stop 流程和基础质量命令通过。

## 推荐用例

1. 有效且在保订单 → 给出保内处理路径。
2. 有效但过保订单 → 给出人工审核或付费维修路径。
3. 不存在订单 → 明确查无记录。
4. 工具模拟超时 → 说明暂时无法查询并转人工。
5. 用户同时说多个订单号 → 逐一确认，不混淆结果。

## 证据

- fixture 输入和工具返回日志。
- transcript 中的订单号、结果和升级原因。
- API/工具合同测试及 quickstart 基础验证命令。
